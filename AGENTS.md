# AGENTS.md

## Arbejdsregler

- Arbejd i små, selvstændige opgaver.
- Undersøg kun relevante filer før en ændring.
- Genbrug eksisterende React-, Zustand-, TanStack Query- og Lingui-kode.
- Implementér én opgave ad gangen og test efter hver ændring.
- Lav ikke arkitekturændringer uden at forklare hvorfor.
- Bevar dansk brugerflade, responsivt design og dataminimering.
- Implementér ikke multiplayer eller ændr eksisterende funktionalitet uden godkendt plan.

## Testkrav

- Kør mindst `npm run typecheck`, `npm run lint` og relevante Vitest-/Playwright-tests.
- Kør `npm run build`, når ændringer påvirker build, routing eller oversættelser.
- Ret fejl, som egne ændringer introducerer, før næste opgave.

## Kommunikation

- Svar kort på dansk.
- Opdatér `PLAN.md` og `PROGRESS.md` efter afsluttede opgaver.
